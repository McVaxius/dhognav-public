# DhogNav

DhogNav is a FINAL FANTASY XIV plugin by McVaxius. The free public plugin provides an introduction and loads modules whose access is granted privately by the owner. Open it with `/dnav`.

## Community and access

Join [The Dumpster Fire community on Discord](https://discord.gg/VsXqydsvpu) for discussion and access arrangements. You can also [support McVaxius on Ko-fi](https://ko-fi.com/mcvaxius). Support does not automatically grant module access.

Keep the public DhogNav plugin installed. When given a DhogNav access ZIP, copy its direct HTTPS attachment link, open `/apm`, add the installed DhogNav plugin to the list, trust the publisher, enable **Advanced options**, and **Ctrl+click the second refresh icon**. APM installs the access file and reloads DhogNav. Open `/dnav` to confirm the module initialized. This requires an APM build with DhogNav access support.

The first refresh icon is for replacing a development plugin's normal installation files. Access ZIPs use the second icon; they do not replace the public host.
